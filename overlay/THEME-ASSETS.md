# Theme assets

The theme backgrounds are static 1920x1080 PNG textures generated for the application.

- `walnut.png`: warm walnut / black hi-fi front panel with amber accents.
- `silver.png`: brushed silver classic tuner with warm display accents.
- `graphite.png`: dark graphite studio front panel with teal/amber accents.

Dynamic station information is overlaid by RmlUi; no radio controls or station names are baked into the background textures.
