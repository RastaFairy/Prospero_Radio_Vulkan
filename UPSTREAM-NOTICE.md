# Aviso sobre el proyecto de origen

ProsperoRadio es una aplicación homebrew de PS5 de código abierto, publicada por `blackbearreloaded` bajo la licencia GPL-3.0-or-later.

Esta bifurcación parte de la revisión `33898dd35375c1ae8370da137cfb6941d91c7684` del proyecto original y añade una ruta gráfica Vulkan, una interfaz con el frontal de una radio, una textura KTX2 de alta resolución y las herramientas para compilar esta integración. El lanzador prepara esa revisión en una caché externa y aplica allí los archivos de `overlay/`.

Proyecto original: [blackbearreloaded/ProsperoRadio](https://github.com/blackbearreloaded/ProsperoRadio)

Renderizador Vulkan para PS5: [mihawk-99/PS5_Vulkan](https://github.com/mihawk-99/PS5_Vulkan)

Consulta las licencias de los componentes originales y de terceros antes de redistribuir una compilación.
