# Créditos

## Autoría y mantenimiento

- **BlackBearReloaded** — autoría del proyecto Prospero Radio original del que
  deriva este fork.
- **RastaFairy** — mantenimiento de Prospero Radio Vulkan, definición de la
  interfaz y validación funcional en PS5.

El historial Git recoge estas dos identidades de autoría. Las observaciones de
consola, las capturas de la v042 y las referencias visuales fueron aportadas por
RastaFairy.

## Componentes y licencias

Prospero Radio Vulkan integra o deriva trabajo de **PS5_Vulkan**, **Mesa**,
**RmlUi** y **SDL**. Sus avisos y licencias se conservan junto a cada componente
en el repositorio. El fork mantiene GPL-3.0-or-later; consulta [`LICENSE`](../LICENSE)
y el resumen informativo [`LICENSE-ES.md`](../LICENSE-ES.md). La licencia del
proyecto original y las de terceros prevalecen para sus respectivos archivos.
